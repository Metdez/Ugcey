<objective>
Persistence that survives container restarts with no external database. This plan builds three things:
- a KV client for `state.internal` (plus sqlite and memory variants);
- write-through mirrors of LangGraph's `InMemorySaver` and `InMemoryStore`;
- the AppStore system of record on D1 (over `bindings.internal`) and on SQLite locally, both driven by one migration file.

It also builds the shared internal HTTP client.
</objective>

<tasks>
1. **`ugecy/internal.py`.**
   - `client(host: str) -> httpx.AsyncClient`. In edge mode it uses `base_url=f"http://{host}"`; in local and test mode it raises if called. Keep one shared client per host.
   - `async post_json(host, path, body) -> dict`. Raise `InternalError(code, message)` on non-2xx, parsed from the `{"error":{...}}` envelope.
   - **Edge-only fallback flag:** `UGECY_INTERNAL_MODE`.
2. **`ugecy/persistence/kv.py`.** `EdgeKV(settings)` calls `state.internal` `/kv/get|put|delete` with base64 values. Batch `put` in chunks of ≤ 200 items and ≤ 4 MB of payload. `SqliteKV(settings)` uses `{data_dir}/state.db`, run with `aiosqlite` or `asyncio.to_thread` over sqlite3; prefer stdlib + `to_thread`. `MemoryKV(settings)` is a dict.
3. **`ugecy/persistence/checkpointer.py`.** `MirroredSaver(InMemorySaver)`:
   - **Writes.** Override the async methods the graph uses (`aget_tuple`, `alist`, `aput`, `aput_writes`, `adelete_thread`, and any delta-history method langgraph 1.2.20's base class calls; check the source).
   - **Lazy hydration.** On first touch of a `thread_id`, load KV ns `ckpt:<thread_id>` into `self.storage`, `self.writes` and `self.blobs`.
   - **Write-through.** After each `put` / `put_writes`, persist exactly the new or changed entries, keyed so that hydration can rebuild the dicts. Suggested keys:
     - `c|<ns>|<checkpoint_id>`: the checkpoint tuple
     - `w|<ns>|<checkpoint_id>|<task_id>|<idx>`: pending writes
     - `b|<ns>|<channel>|<version>`: blobs
   - **Encoding.** Serialize tuple pieces with pickle or JSON+base64 of the serde-typed bytes. They are already `(type, bytes)` typed values from the serde, so wrap them with a stable encoding and **no pickle of arbitrary objects** beyond what InMemorySaver already holds (typed bytes).
   - **Concurrency.** Keep an `asyncio.Lock` per thread.
   - **Factory.** `build_checkpointer(kv) -> MirroredSaver`.
4. **`ugecy/persistence/store.py`.** `MirroredStore(InMemoryStore)`:
   - Hydrate everything from KV ns `store` at startup (memories and skills are small).
   - Write-through on `abatch`/`batch` `PutOp` and deletes. Key = `json([namespace..., key])`; value = the JSON item value plus `created_at` / `updated_at`.
   - Factory: `async build_store(kv) -> MirroredStore` (hydrated).
   - Export both factories from `ugecy/persistence/__init__.py`.
5. **`migrations/0001_init.sql`** (repo root; the Worker applies it to D1 and the local sqlite applies the same file).
   - Tables: `threads`, `audit`, `assets`, `posts`, `accounts`, `approvals`, `sources`. Columns mirror `contracts.py` models.
   - JSON fields are TEXT: `requests`, `args`.
   - Indexes on `thread_id` and `ts` / `created_at`.
   - Primary keys: `id` / `interrupt_id`; `sources` uses `PRIMARY KEY(thread_id, url)`.
   - Use `CREATE TABLE IF NOT EXISTS`.
6. **`ugecy/persistence/appstore.py`.** `SqlAppStore` implements the `AppStore` Protocol over a small `SqlExecutor` with `async query(sql, params) -> list[dict]` and `async execute(sql, params)`. Use upsert via `INSERT ... ON CONFLICT DO UPDATE`.
   - `SqliteAppStore(settings)`: the executor is sqlite3 under `to_thread`, file `{data_dir}/app.db`, or `:memory:` in test mode. `init()` runs the migration file; locate it via a path relative to the repo, plus a copy bundled as package data at `ugecy/persistence/schema.sql` that you keep in sync with a test asserting both files are equal.
   - `D1AppStore(settings)`: the executor posts to `bindings.internal` `/d1/query`. `init()` is a no-op, because the Worker applies migrations.
   - Both convert rows to and from the contracts models.
   - **Two registered names.** `deps.IMPLEMENTATIONS` references `ugecy.persistence.appstore:D1AppStore` and `:SqliteAppStore`.
7. **`ugecy/persistence/edge.py`.**
   - `EdgeBindingsClient(settings)`: implements `EdgeBindings` over `bindings.internal`.
   - `LocalEdgeBindings(settings)`:
     - `browser_markdown`: httpx GET with a 15 s timeout and a browser-like UA, plus a minimal HTML→text conversion (strip scripts and styles, collapse whitespace, take the `<title>`). Use stdlib `html.parser`; don't add bs4.
     - Vectors: in memory, with naive token-overlap scoring.
     - `media_ingest`: returns `{asset_id, playback_url: url, thumbnail_url: None}`.
     - `schedule_publish`: returns `"local-" + post_id`. Publishing then happens immediately, which the tool layer handles.
     - `metric`: no-op.
8. **Tests.**
   - **Checkpointer.** Run a tiny LangGraph `StateGraph` (counter plus `messages`) with the `MirroredSaver` over `MemoryKV`. Run it, then create a **new** `MirroredSaver` on the same KV (a simulated restart), then `aget_state` and continue. History and the next step must be intact. Also cover an interrupt followed by a resume after the restart, using `langgraph.types.interrupt`.
   - **Store.** Put, then restart, then search.
   - **AppStore.** CRUD round-trips with sqlite `:memory:`.
   - **EdgeKV.** Against an `httpx.MockTransport`.
</tasks>
