<tasks>
1. **`ugecy/integrations/research/web.py`.** Build `WebResearchProvider(settings)`, which implements `ResearchProvider` (`name="web"`).
   - **`search`:**
     - With Firecrawl configured (edge: `settings.has_firecrawl`, using `ugecy.internal.post_json("firecrawl.internal", "/v2/search", ...)`; local: `settings.firecrawl_api_key`, calling https://api.firecrawl.dev directly), return `Source`s with platform inferred from the domain.
     - Otherwise fall back to the mock library (`mode` reports `"mock"` in that case; the `mode` attribute reflects the configuration at init).
   - **`fetch`:**
     - For TikTok, YouTube and Instagram URLs, call public oEmbed (title, author, thumbnail) via httpx. In edge mode, external hosts other than the `*.internal` intercepts are NOT reachable, so route the fetch through `get_deps().edge.browser_markdown(url)`, which runs at the edge.
     - Otherwise call `get_deps().edge.browser_markdown(url)`.
     - Return `{url, title, platform, markdown (≤ 20k chars), metrics: {} }`.
     - Leave a `shortcut:` comment noting that oEmbed in edge mode needs an edge route (v2).
2. **`ugecy/integrations/research/mock.py` and `samples.py`.** Build `MockResearchProvider` with a curated library of 24 realistic sample patterns across niches (skincare, supplements, fitness apps, SaaS, food, fashion). Each sample has:
   - a hook line;
   - a hook type (from the FEATURES.md taxonomy);
   - structure beats;
   - a format (testimonial, problem-solution, POV, unboxing, street-interview, green-screen, before-after);
   - illustrative metrics;
   - a plausible platform.

   Mark each sample **SAMPLE DATA**, and give it the URL `https://example.com/sample/<slug>`, never a fake real URL. Search ranks samples by token overlap.
3. **`ugecy/tools/research.py`.** Define tools with `@tool` and register each with `registry.register_tool(t, domain="research")`.
   - **`web_search(query: str, platform: str | None = None, limit: int = 8) -> str`:** returns compact JSON lines. For each source, call `emit("source.added", source=...)` and `await get_deps().app.add_source(thread_id, source)`, with `thread_id` from `events.current_thread_id()`.
   - **`fetch_page(url: str) -> str`:** validates http(s) URLs and rejects private, internal hosts. Emits the source and returns the markdown head (≤ 8k chars) plus metadata.
   - Docstrings must tell the model when to use each tool and that only public, permitted pages are allowed.
4. **`ugecy/tools/memory.py`.** Register with `domain="memory"`.
   - **`remember_pattern(title, hook, hook_type, structure, why_it_works, source_urls: list[str], tags: list[str]) -> str`:** calls `get_deps().edge.vectors_upsert(namespace=f"{ws}:patterns", items=[{id: slug, text, metadata}])` and emits `memory.updated`.
   - **`search_patterns(query: str, top_k: int = 5) -> str`:** calls `vectors_query`, falling back to the mock samples when there are no matches. Results are labelled.
5. **`ugecy/tools/creative.py`.** Register **`compliance_check(text: str, platform: str = "tiktok", is_ai_generated: bool = True, is_paid_partnership: bool = False) -> str`** with `domain="creative"`. It is deterministic and must not call an LLM. Rules come from FEATURES.md and COMPETITORS.md:
   - flag banned or unsubstantiated health and financial claims ("cure", "guaranteed", "lose X lbs in", "clinically proven" without a source, "doctor recommended", and so on);
   - check for FTC `#ad` / `#sponsored` disclosure when the post is a paid partnership;
   - add an AI-label requirement per platform;
   - flag fake-testimonial phrasing when the content is AI-generated ("I tried", "my results" spoken by an AI actor);
   - warn on caption length limits.

   Return JSON `{verdict: pass|fix|block, issues:[{rule, severity, excerpt, fix}]}`.
6. **`ugecy/integrations/publishing/analytics.py`.** Build `MockAnalytics(settings)`, which implements `AnalyticsProvider`. It returns deterministic pseudo-metrics per post (seeded by `post.id`): views, likes, shares, saves, watch-time %, and a 7-day curve.
   - **`ugecy/tools/analytics.py`:** register **`get_post_metrics(post_ids: list[str] | None = None) -> str`** with `domain="analytics"`. It loads posts via `deps.app.list_posts()` and labels the output mock.
7. **Tests.** Every tool registers under the exact names listed in `ugecy/modules.py`. Cover:
   - `compliance_check` cases;
   - mock search ranking;
   - `fetch_page` URL validation (rejects `http://localhost` and `169.254.169.254`);
   - `web_search` emitting sources (call the tool function with a fake deps installed via `set_deps`).
</tasks>
