2. **`worker/do/agent-runtime.ts`**: replace the stub. `AgentRuntime` extends `DurableObject<Env>`:
   - `fetch(req)` calls `ensureReady()` (start the container if it isn't running), then forwards to `ctx.container.getTcpPort(8000).fetch(...)` and returns the response directly, so SSE streams through unbuffered.
   - Start options:
     - `enableInternet: false`
     - instance `standard-1`
     - env:
       - `UGECY_INTERNAL_MODE=edge`
       - `UGECY_WORKSPACE_ID`
       - `UGECY_HAS_HIGGSFIELD` = `env.HF_KEY ? "true" : "false"`
       - `UGECY_HAS_FIRECRAWL` = `env.FIRECRAWL_API_KEY ? "true" : "false"`
       - `UGECY_HAS_GLASSHAND` = `env.GLASSHAND_TOKEN ? "true" : "false"`
       - `UGECY_DATA_DIR=/tmp/ugecy`
   - Register `interceptOutboundHttp` for `llm.internal`, `state.internal`, `bindings.internal`, `higgsfield.internal`, `firecrawl.internal` and `glasshand.internal` → `ctx.exports.EgressGateway({props: {runtimeId: ctx.id.toString()}})`. Check how `ctx.exports` / loopback entrypoints work in current docs.
   - Inactivity timeout: 30 min.
   - Readiness polls `/healthz` for up to 60 s. Python import is slow.
   - RPC methods `kvGet(ns, prefix)`, `kvPut(ns, items)` and `kvDelete(ns, prefix)` over `ctx.storage.sql`, table `kv(ns, key, value BLOB, updated_at)` with `PRIMARY KEY(ns, key)`. Values cross RPC as base64 strings or ArrayBuffers.
   - **Keep the code container-API-agnostic** behind small helpers in this file, so an API change stays local.
3. **`worker/egress/gateway.ts`**: `export class EgressGateway extends WorkerEntrypoint<Env, RuntimeProps>` routes by hostname:
   - `llm.internal`: `llm.ts`
   - `state.internal`: `state.ts` (calls the AgentRuntime DO RPC via `env.AGENT_RUNTIME.get(env.AGENT_RUNTIME.idFromString(props.runtimeId))`)
   - `bindings.internal`: `import { handleBindings } from "./bindings"` (owned by 02-10; it exists as a stub until they finish)
   - `higgsfield.internal` / `firecrawl.internal` / `glasshand.internal`: `vendors.ts`
   - anything else: 403, plus `env.METRICS.writeDataPoint`
   
   If `worker/egress/bindings.ts` does not exist yet, create a stub that exports `handleBindings` returning 501. 02-10 will overwrite it.
4. **`worker/egress/llm.ts`**: the OpenAI-compatible handler over `env.AI.run(model, body, opts)`:
   - Enforce the allowlist in INTERNAL-API.md.
   - For `stream:true`, pipe the returned ReadableStream through a line filter: keep `data: [DONE]`, drop `data:` JSON lines without `choices`, and pass everything else through.
   - For non-stream, return JSON.
   - `/v1/embeddings` maps to `env.AI.run(model, {text: input})` and reshapes to the OpenAI embeddings response. Check the Workers AI embedding I/O schema.
   - Gateway option: pass `{gateway: {id: env.AI_GATEWAY_ID}}` only if it is set.
   - On upstream error, return the status plus the `{"error": {...}}` envelope. On a 429 from a paid model, return 429 so the Python fallback middleware engages.
5. **`worker/egress/vendors.ts`**: passthrough to `https://api.higgsfield.ai` with `Authorization: Key ${env.HF_KEY}`, Firecrawl with `Bearer`, and Glasshand with `Bearer`.
   - Strip any incoming `authorization` header.
   - Missing secret returns 503 `not_configured`.
   - Paths are allowlisted by prefix:
     - Higgsfield: everything except `/v1/agent`
     - Firecrawl: `/v2/search` and `/v2/scrape`
     - Glasshand: `/v1/rentals`
6. **`worker/auth.ts`**:
   - `GET /api/edge/unlock?key=...`: when it matches `env.UGECY_ACCESS_KEY` (constant-time compare), set the cookie `ugecy_key=<sha256(key)>; HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=2592000`, then 302 to `/`. Otherwise return 401 HTML.
   - Middleware for `/api/*`, except `/api/edge/*`: require the cookie hash, otherwise 401 JSON `{"error":{"code":"locked","message":"Open the access link to unlock"}}`.
7. **`worker/index.ts`** (Hono):

   - `/api/*`: proxied with `worker/proxy.ts` to `env.AGENT_RUNTIME.getByName(env.WORKSPACE_ID)` (or `idFromName` + `get` if `getByName` is unavailable). Pass the method, headers and body through, and return the response unmodified.
   - Export `default { fetch, queue }`. Queue comes from `import { handleQueue } from "./queues/consumer"`, owned by 02-10; create a stub if missing.
   - Export `AgentRuntime`, `EgressGateway`, and `PublishWorkflow` (from `./workflows/publish`, owned by 02-10; stub if missing).
