<tasks>
1. **`ugecy/main.py` app factory and lifespan:**
   - `settings = get_settings()`, then `deps = build_deps(settings)`, then `await deps.app.init()`.
   - `deps.checkpointer = build_checkpointer(deps.kv)` and `deps.store = await build_store(deps.kv)`.
   - Call `load_modules()`, then `await seed_store(deps.store, settings.workspace_id)`, then `set_deps(deps)`, then `app.state.agent = build_agent(deps)`.
   - In `internal_mode="test"`, allow `app.state.agent` to be injected (`create_app(agent=..., deps=...)`).
   - Keep `/healthz` and also serve it as `/api/healthz`.
   - Ensure a default mock account set exists at startup if `list_accounts()` is empty: `tiktok @demo_brand`, `instagram @demo_brand` and `youtube @demo_brand`, all `mode="mock"`.
2. **`ugecy/runs.py` RunManager**, one active run per thread:
   - `start(thread_id, input_or_command) -> run_id` launches an `asyncio.create_task` that iterates `agent.astream(input, config={"configurable": {"thread_id": tid}, "recursion_limit": 400}, context=RunContext(...), version="v2", subgraphs=True, stream_mode=["messages", "updates", "custom", "values"])`.
   - Events go through the adapter into a per-run buffer (a list plus an `asyncio.Condition`), with `seq` assigned.
   - Subscribers (SSE responses) read from `since`. A disconnecting subscriber **does not** cancel the run, but `cancel(thread_id)` does.
   - Update the thread status in AppStore: `running` / `awaiting_approval` / `idle` / `error`, and `updated_at`.
   - Keep the last run's buffer per thread for reconnect.
3. **`ugecy/stream/adapter.py`**: a pure-ish class `StreamAdapter(thread_id, run_id)` with `feed(part) -> list[UiEvent]`. Field names follow events.ts. The mapping:
   - **Agent name** comes from `metadata["lc_agent_name"]` (orchestrator name `ugecy-orchestrator`; map it to "orchestrator"). `ns` is `part["ns"]` as a list. `parent_call_id` comes from `metadata.get("lc_subagent_tool_call_id")`, or is parsed from `ns` `"tools:<id>"`.
   - **`messages` parts:**
     - `AIMessageChunk` text becomes `message.delta`, and the reasoning in `additional_kwargs["reasoning_content"]` becomes `reasoning.delta`. Skip empty strings.
     - Completed tool calls are detected in the `updates` parts (model node message with `tool_calls`). Each one emits `tool.started` exactly once per call id. For `name == "task"` it also emits `subagent.started`, with subagent = `args["subagent_type"]` and description = `args["description"]`.
   - **`ToolMessage` in `updates` (tools node)** emits `tool.completed`, with status error if `msg.status == "error"`, and `output_preview` truncated to 2000 characters. For `task` it also emits `subagent.completed` with summary = the content truncated to 600 characters.
   - **`values` at `ns == ()`** emit `todos.updated` and `files.updated` only when they changed. Files come from the `files` dict `{path: FileData}`, with size = len(content) and modified_at from FileData.
   - **`custom` parts** whose dict `type` is in `CUSTOM_TYPES` map directly to UiEvents with the same fields.
   - **`updates` with `__interrupt__`** emit `approval.requested`. Here `interrupt_id = Interrupt.id` and each `action_request` becomes an `ApprovalRequest`:
     - `tool` = name; `args`; `description`; `allowed_decisions` comes from the matching `review_configs`
     - `agent` = the registry agent that owns the tool
     - `estimated_cost_usd` is filled for `generate_media` via `estimate_for_approval`
   - Also persist an `ApprovalRecord(status="pending")` via AppStore and write an audit entry (action "approval", status "pending").
   - **End of stream:** emit `run.completed` with status `interrupted` if there was an interrupt, else `done`. Exceptions produce `error` (retryable when the error is a 429 or timeout) followed by `run.completed{status:"error"}`.
   - Start every run with `run.started` (model = `settings.model_orchestrator`).
   - Message ids: use the chunk `.id`. Many models stream chunks with the same id per message.
   - Unit-test the adapter with recorded or synthetic parts, including a subagent namespace and an interrupt.
4. **`ugecy/api/*.py` routers** (each ≤ 300 lines), following api.ts exactly:
   - **threads:** list, create, get, delete. GET returns `ThreadState`:
     - messages come from `agent.aget_state(cfg).values["messages"]` converted to `ChatMessage` (Human→user, AI→assistant with `tool_calls` and reasoning, Tool→tool)
     - todos and files come from the values
     - sources come from `deps.app.list_sources`
     - `pending_approval` comes from `state.interrupts` if present, else None
   - **runs:** create a thread if it's unknown. A 409 is returned if a run is already active.
   - **resume:** body `ResumeRequest`. Map each `Decision` as follows:
     - approve → `{"type": "approve"}`
     - edit → `{"type": "edit", "edited_action": {"name": <tool>, "args": d.args}}`
     - reject → `{"type": "reject", "message": d.message or "Rejected by operator"}`
     
     Then resume with `Command(resume={"decisions": [...]})`. If the thread has more than one pending interrupt, use `Command(resume={interrupt_id: {"decisions": [...]}})`. Update the `ApprovalRecord` (approved / edited / rejected) and write an audit entry for each decision (actor operator).
   - **stream** reconnect, **cancel**, **files**: `GET ?path=` reads from the state `files`; 404 if missing.
   - **memories:**
     - GET lists `deps.store.asearch(memories_ns(ws))` plus `asearch(SKILLS_NS)`, mapped to `MemoryFile`; the path is `/memories` + key and `/skills` + key.
     - PUT accepts only paths under `/memories/` and puts a FileData dict.
   - **assets, approvals, audit, accounts, posts:** read through AppStore.
   - **device:** status comes from `device_status_snapshot()`; screenshot returns `deps.device.screenshot(first device)` as `image/jpeg`.
   - **config:** `AppConfig` with version, modes, models from settings, agents from the registry (name, description, model id resolved via `settings.model_for(role)`, tools, enabled), and the six starter prompts from UI-SPEC §6.
   - **jobs:** `POST /jobs/publish` takes `{post_id}` and an `Idempotency-Key` header, and calls `run_publish_job`. It is **not** under `/api` because the Worker never exposes it publicly.
   - **SSE:** use `sse_starlette.EventSourceResponse` with `ping=15`, `event=<type>` and `data=json(event.wire())`. Set headers `Cache-Control: no-cache` and `X-Accel-Buffering: no`.
   - **Errors:** use the `{"error": {"code", "message"}}` envelope via exception handlers.
5. **Tests** (`tests/test_api_*.py`, `tests/test_stream_*.py`), using `httpx.AsyncClient(transport=ASGITransport(app))` and a fake agent:
   - create thread → run → read SSE until `run.completed`
   - an interrupting tool → `approval.requested` → resume approve → tool executed
   - reconnect with `since`
   - the `/api/config` shape
</tasks>
