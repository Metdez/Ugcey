<tasks>
1. **Plan tab.** Progress "3 of 7", a "To do" section, and a collapsible "Completed" section. Status icons are pending ○, in_progress (spinner) and completed ✓.
2. **Agents tab.**
   - Running and completed subagent run cards: avatar color, name, status, duration, two-line task, tool count and model.
   - Clicking a card opens a detail view with the task, the nested tool calls (`toolCallIds` → `toolCalls`), streamed text and the result.
   - A team roster from `/api/config` agents: name, description, model, tools and enabled state.
   - Honour `useUi().focus` when its kind is `subagent`.
3. **Files tab.**
   - A file tree from `files` paths, grouped by the first segment (/plans, /research, /briefs, /scripts, /reviews, /publishing…).
   - A viewer that loads content via `api.getFile(threadId, path)`. Markdown renders with react-markdown; JSON and other text render as mono. Include Copy and Download.
   - Focus support: `focus.kind==='file'` opens that path.
4. **Memory tab.**
   - Lists `api.listMemories()`, grouped by "Long-term (/memories)" (editable: inline edit, then `api.putMemory`) and "Playbooks (/skills)" (read-only, shown with a SKILL badge).
   - An "Add memory" form creates `/memories/<slug>.md`.
   - Show the notice "Memory changes apply to new threads".
5. **Sources tab.** Platform filter chips (All/TikTok/IG/YT/Web) and items with favicon (`https://icons.duckduckgo.com/ip3/<domain>.ico` is ok), title, domain, platform and snippet. Footer: "Analyzed for patterns only — never re-published".
6. **Assets tab.** All, Images and Videos filters; status filter; a two-column grid of `AssetThumb`; click calls `openLightbox`. Merge the thread assets with `api.listAssets()`.
7. **Approvals tab.** "Pending" uses `ApprovalCard variant="panel"` for `approvals` in the current thread with status pending. "History" comes from `api.listApprovals()` and shows decision, time and tools.
8. **Audit tab.** Rows show `HH:mm:ss`, an actor icon, agent, action chip, tool, status icon and mode badge. Expanding a row shows the detail. Filter by status. Live toggle (polling). Export JSON.
9. **Device tab.**
   - Uses `api.getDevice()`. The header shows the provider, a MOCK badge, `control` state and the last action.
   - An iPhone frame (aspect 393:852, `rounded-[3rem] border-[10px] border-neutral-900`, dynamic island) whose screen is an `<img src={api.deviceScreenshotUrl()}>` refreshed every 2 s while visible.
   - The session panel shows goal and steps used/max, or the empty state "No device session. The device operator asks for approval before it connects."
   - A receipts list of recent device audit rows (filter audit by `tool` starting with `device_`).
   - A note: "Live iPhone streaming via Glasshand arrives when a device is connected".
10. **Empty states** for every tab, per UI-SPEC §5.4. Use a simple EmptyState from WP-A's `common/empty-state` if it exists; otherwise make your own in `inspector/empty.tsx`.
11. **Tests:** file-tree grouping and audit filtering (pure functions).
</tasks>
