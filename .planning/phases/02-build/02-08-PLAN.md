<tasks>
1. **`ugecy/integrations/media/higgsfield.py`**: `HiggsfieldProvider(settings)`, an httpx adapter of about 200 lines.
   - Base URL is `http://higgsfield.internal` in edge mode (the Worker injects auth). In local mode it is `https://api.higgsfield.ai` with `Authorization: Key {settings.higgsfield_key}`.
   - `submit` sends `Idempotency-Key`, never retries a POST without the same key, and honours `Retry-After` on 429.
   - `get` uses `GET /requests/{id}/status`. `estimate` uses `POST /estimate/{endpoint_id}`.
   - Map outputs: `images[].url` and `video.url` → `[{url, kind}]`.
   - `catalog.yaml` holds the UGC-relevant models from INTEGRATIONS.md B6 (endpoint_id, kind, label, defaults: aspect_ratio 9:16, …). `models()` reads it.
   - **Never log the key.**
2. **`ugecy/integrations/media/mock.py`**: `MockMediaProvider`.
   - Uses the same catalog. Jobs go queued → in_progress → completed by elapsed time (2 s and 6 s).
   - Outputs are data-URI SVG placeholders. Videos get a 9:16 SVG poster plus `kind:"video"`, and a tiny bundled mp4 if you can produce one without new deps, otherwise the poster.
   - Supports fault injection markers in the prompt: `[mock:fail]` and `[mock:nsfw]`.
3. **`ugecy/tools/media.py`** (domain media):
   - `list_media_models(kind=None)`.
   - `estimate_media_cost(model, args)`.
   - `generate_media(model: str, prompt: str, kind: str = "video", args: dict | None = None, brief_path: str | None = None)`.
     - Register it with `interrupt=APPROVE_EDIT_REJECT, side_effect=True`.
     - The body runs only after approval. It creates an `Asset` (status queued, `mode=deps.modes.media`) with a server-generated idempotency key, calls `submit`, `upsert_asset`, emits `asset.updated`, writes audit `action="media_job"`, and starts a background poller (`asyncio.create_task`).
     - The poller backs off 2 s ×1.5 up to 10 s, with a 15 min cap. It updates the asset. On completion it calls `get_deps().edge.media_ingest(asset_id, url, kind)` and updates `url` / `thumbnail_url`.
     - It returns the asset id and status JSON.
   - `check_media_job(asset_id)`.
   - Also export `async estimate_for_approval(args: dict) -> float | None`, which reads `args["model"]` and the rest. 02-04 calls it.
4. **`ugecy/integrations/publishing/mock.py`**: `MockPublisher`.
   - `publish(post, asset)` returns `{status:"published", external_url:"https://example.com/mock/<platform>/<post_id>"}` and enforces `ai_disclosure` when the asset is AI-generated.
5. **`ugecy/tools/publishing.py`** (domain publishing):
   - `list_connected_accounts()`.
   - `publish_post(account_id: str, asset_id: str, caption: str, ai_disclosure: bool, publish_at: str | None = None)`.
     - Register it with `interrupt=APPROVE_EDIT_REJECT, side_effect=True`.
     - Validate:
       - the account exists;
       - the asset exists and is `completed`;
       - `ai_disclosure` is true for AI media (refuse otherwise);
       - the caption length is within platform limits.
     - Create a `Post` with status `scheduled` if `publish_at` is in the future, else publish now.
     - **Scheduled:** call `edge.schedule_publish(post_id, publish_at)`. Locally, publish immediately with a note.
     - **Now:** call `await run_publish_job(post_id)`.
     - Write audit `action="publish"`.
   - `get_post_status(post_id)`.
   - Export `async run_publish_job(post_id) -> dict`. It is idempotent: a no-op if the post is already published. It publishes via `deps.publisher`, updates the post, and writes an audit entry. 02-04 exposes it at `POST /jobs/publish`.
6. **`ugecy/integrations/device/mock.py`**: `MockDeviceProvider`.
   - One device `iphone-mock-1` named "Mock iPhone SE".
   - A JSON screen graph of about 6 screens: Home → Photos → TikTok-like upload → Caption → Posted, plus a Safari handoff page.
   - Each screen is rendered with Pillow at 750×1334: a title bar, labelled hotspot rectangles, the last action overlay, and a clock.
   - `send` handles tap (normalized x,y) by hit-testing hotspots, plus swipe, type (ASCII ≤ 512), home and receipts.
   - `describe()` lists the screen name and its hotspots, so non-vision models can act.
   - Thread-safe state.
7. **`ugecy/integrations/device/glasshand.py`**: `GlasshandProvider`, REST only, over `http://glasshand.internal` (edge) or the API directly (local).
   - Implements `list_devices` (rentals with `deviceReady` and status active/grace), `screenshot` (crop to the viewport using Pillow), and `send` (`POST /rentals/{id}/input` with `Idempotency-Key`).
   - Add a `shortcut:` comment noting that stream relay and device-flow auth are v2.
8. **`ugecy/tools/device.py`** (domain device):
   - `device_status()` and `device_screenshot()`. The screenshot tool returns the `describe()` text and records the last action.
   - `device_start_session(goal: str, allowed_apps: list[str], max_steps: int = 25)`, registered with `interrupt=APPROVE_REJECT`.
   - `device_tap(x, y)`, `device_swipe(from_x, from_y, to_x, to_y)`, `device_type(text)` and `device_home()`.
     - **Guarded in code:** they require an active approved session and a remaining step budget, otherwise they return an error string.
   - `device_commit(intent: str, x: float, y: float)`, registered with `interrupt=APPROVE_REJECT, side_effect=True`.
   - Every action writes an audit row with tool `device_*`.
   - Export `async device_status_snapshot() -> DeviceStatus` for the API.
   - Session state lives in module-level memory. Add a `shortcut:` comment.
9. **Tests**:
   - mock media lifecycle and fault injection;
   - the Higgsfield adapter against `httpx.MockTransport` (idempotency header, Retry-After, output mapping);
   - publish validations, including refusal without disclosure;
   - `run_publish_job` idempotency;
   - mock device tap hit-testing and the session guard;
   - every tool registered with the expected interrupt config.
</tasks>
