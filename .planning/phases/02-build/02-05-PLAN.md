1. **`ugecy/llm/workers_ai.py`**
   - `ChatWorkersAI(ChatOpenAI)`: copy it from MODELS.md (reasoning capture, content normalization).
   - `make_model(role, settings) -> ChatWorkersAI`. The base URL depends on the internal mode:
     - edge: `base_url="http://llm.internal/v1"`, `api_key="intercepted"`
     - local: `base_url="https://api.cloudflare.com/client/v4/accounts/{cf_account_id}/ai/v1"`, `api_key=cf_api_token`
   - Common settings: `use_responses_api=False`, `timeout=settings.llm_timeout_s`, `max_retries=1`, `profile={"max_input_tokens": <ctx>}` (glm-5.3 / deepseek: 1_000_000 capped at 200_000 for summarization sanity; qwen3.8: 262_144; glm-4.7-flash: 131_072).
   - Per-model kwargs come from MODELS.md (glm-4.7-flash: thinking off via `extra_body`). Never use `tool_choice="required"`.
   - `ugecy/llm/routing.py`: `models_for(settings) -> dict[role, BaseChatModel]` for the roles orchestrator, research, creative, critic, fast, vision, plus `fallback`.
2. **`ugecy/middleware/`** (each file is small):
   - `audit.py`: `AuditMiddleware(AgentMiddleware)` with `awrap_tool_call`. It writes an `AuditEntry` via `get_deps().app.add_audit` with fields:
     - `actor="agent"`, `agent` from `request.runtime`/config metadata `lc_agent_name` (best effort)
     - `action="tool_call"`, `tool` = name
     - `status` = ok or error
     - `mode` = `deps.modes.<domain>` for the tool's registry domain (llm when the tool isn't registered, for example the built-in fs tools)
     - `detail` = args JSON truncated to 300 characters
     
     Audit failures must never break the tool call; log them and continue.
   - `compat.py`: adapted from DEEPAGENTS.md §9 (Nemotron helpers):
     - strip leaked `<think>…</think>` from AI content
     - parse text tool calls (`<tool_call>{json}</tool_call>`) into `tool_calls` when `tool_calls` is empty
     - when the model narrates "I'll call X" without calling any tool in the middle of a plan, nudge it once
     
     Keep it under 200 lines and test it.
   - Limits: use langchain's `ModelCallLimitMiddleware(run_limit=settings.max_model_calls_per_run, exit_behavior="end")`, `ModelRetryMiddleware(max_retries=2, backoff_factor=2.0)` and `ModelFallbackMiddleware(<fallback model>)`. Verify the class names exist in langchain 1.4.9 (`langchain.agents.middleware`); if one doesn't, write the minimal equivalent.
3. **`ugecy/agents/<name>.py`**, one module per subagent. Each calls `register_agent(AgentModule(...))` at import, with tool names exactly as listed in `ugecy/modules.py` comments (02-07 and 02-08 register them):
   - **research-analyst** (role research). Tools: `web_search`, `fetch_page`, `remember_pattern`, `search_patterns`.
     - It finds winning short-form UGC and turns each into a pattern card in `/research/patterns/<slug>.md`, using the FEATURES.md §1.6 schema: hook type, first 3 seconds, structure beats, payoff, CTA, why it works, metrics, source URLs.
     - It uses only public, permitted sources, cites every URL, and never copies scripts verbatim.
   - **creative-strategist** (role creative). Tools: `search_patterns`.
     - It writes original briefs and 3–5 script variants to `/briefs/` and `/scripts/`, with hook variants across different hook types, beat timings for 15/30/45 s, on-screen text and a shot list.
   - **compliance-critic** (role critic). Tools: `compliance_check`.
     - It scores scripts against a rubric (hook strength, originality vs sources, claim safety, FTC `#ad` disclosure, platform AI-label readiness, brand fit) and writes `/reviews/<script>.md` with a verdict and required edits. It never approves health claims.
   - **production-coordinator** (role fast). Tools: `list_media_models`, `estimate_media_cost`, `generate_media`, `check_media_job`.
     - It turns approved scripts into Higgsfield prompts (subject, setting, camera, lighting, 9:16) and keeps `/assets/manifest.json`.
   - **publishing-coordinator** (role fast). Tools: `list_connected_accounts`, `publish_post`, `get_post_status`.
     - It always sets `ai_disclosure=true` for AI media and includes `#ad` for paid partnerships. It only publishes assets that are completed and approved, to the operator's own connected accounts.
   - **device-operator** (role fast). Tools: `device_status`, `device_screenshot`, `device_start_session`, `device_tap`, `device_swipe`, `device_type`, `device_home`, `device_commit`.
     - It observes → acts → verifies, and uses `device_commit` for the final irreversible tap.
     - It never creates accounts, never handles verification codes, never logs in to accounts, and stops if asked to.
   - **analytics-analyst** (role research). Tools: `get_post_metrics`, `search_patterns`, `remember_pattern`.
     - It reads post metrics, explains winners and losers, and proposes playbook updates (writes to `/memories/playbook.md` require approval).
